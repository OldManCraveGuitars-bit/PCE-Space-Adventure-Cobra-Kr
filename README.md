# PCE-Space-Adventure-Cobra-Kr

**스페이스 코브라 — 흑룡왕의 전설 · PC Engine CD-ROM² 한국어 패치 v0.85**

우주 해적 코브라가 등장하는 SF 어드벤처 게임입니다. 장면을 조사하고 인물과 대화하며 사건을 풀어가는 작품으로, 음성 대사와 영상 연출을 한국어로 즐길 수 있도록 작업했습니다.

## 다운로드

**[v0.85 릴리스 — Windows EXE 패처](https://github.com/OldManCraveGuitars-bit/PCE-Space-Adventure-Cobra-Kr/releases/tag/v0.85)**

- `PCE-Space-Adventure-Cobra-Kr-v0.85-Patcher.exe`: 별도 Python 설치 없이 실행합니다.
- ZIP에는 같은 EXE와 사용 안내·외부 구성요소 라이선스가 들어 있습니다.
- 게임 원본과 BIOS는 포함하지 않습니다. 아래 일본판 원본이 필요합니다.

## 패치 내용

- 원작 로고 디자인을 바탕으로 타이틀·부제·크레딧을 한글화하고 `©1989 HUDSONSOFT`를 중앙 정렬했습니다.
- 등록된 대사·선택지·엔딩 2,750개 항목에 12×12 한글을 적용했습니다. 공백은 반각 6픽셀입니다.
- 음성 자막 165개를 게임 내부에 추가했습니다. 각 줄을 중앙 정렬하고 글자·윤곽선 밖은 투명하게 표시합니다.
- 선택지 848개를 한 줄에 들어가도록 검사했습니다. `통로로 복귀`, `생명유지장치` 등 긴 표현을 정리했습니다.
- 엔딩 글자 잔상, 방 밖 이동 시 진행 정지, 자막 주변 그래픽 손상과 검사 구간의 떨림·감속을 수정했습니다.
- 원래 일본어 음성·음악은 보존합니다. 타이틀의 글자 뒤 배경은 복원 후 새 로고를 합성했습니다.

### v0.85에서 확인하고 보완한 부분

- `그리고 선댄스와`의 마지막 `와`를 입력 대기 표시가 덮어쓰던 문제를 공통 수정했습니다.
- 우주 장면 여학생의 첫 대사와 시민들이 도망갈 때 두 번째 `도와줘요!`를 복구했습니다.
- 음성 목록을 다시 분석해 자막 7개를 추가하고 기존 13개 문구·시간을 보완했습니다. 현재 총 165개입니다.
- 음성이 연속 재생될 때 다음 음성의 업로드 대기 중에도 자막이 갱신되도록 수정했습니다.

## 적용 방법

1. EXE를 실행하고 일본판 원본 **CHD 또는 단일 BIN/CUE**를 선택합니다.
2. 새 출력 폴더를 지정하고 **한국어 패치 만들기**를 누릅니다.
3. `CHD도 생성하기`를 선택하면 BIN/CUE와 CHD를 함께 만듭니다. 원본과 기존 결과는 덮어쓰지 않습니다.
4. 생성된 CHD 또는 CUE로 **전원을 다시 켜서 실행**합니다. BIN과 CUE는 같은 폴더에 둡니다.

**Super CD-ROM² System Card 3.0**이 필요합니다. 이전 패치의 에뮬레이터 세이브스테이트에는 이전 실행 코드가 들어 있으므로 새 이미지에 자동으로 불러오지 마세요. 게임 내 저장과 에뮬레이터 강제 저장은 서로 다릅니다.

출력 드라이브에 약 900MB 이상의 여유 공간을 확보하세요. 여러 BIN으로 나뉜 CUE는 직접 지원하지 않으며, 지원 원본과 같은 데이터로 구성된 CHD 또는 단일 BIN이 필요합니다.
